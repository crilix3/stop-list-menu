# Стоп-лист кухни

Тестовое задание Middle Frontend. Панель стоп-листа: меню смены, фильтры, постановка и снятие стопа.

## Что можно добавить 

1. Предупреждение о том, что какое-то блюдо скоро не смогут приготовить
2. Поиск по названиям блюд
3. Множественный выбор блюд, чтобы поставить их в "стоп"
4. Печать списка блюд
5. Вкладка "Журнал" со всеми "стопами" и "возвратами" блюд
